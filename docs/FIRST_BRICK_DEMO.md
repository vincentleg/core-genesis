# CORE GENESIS — First Brick, three-minute live demo

## Start

From the CORE GENESIS repository:

    npm ci --ignore-scripts
    python3 -m core_genesis.server

The company opens at http://127.0.0.1:8080. Chrome is used for browser testing when installed; otherwise install Playwright Chromium with `npx playwright install chromium`. Python runtime requires only the standard library. Existing Crusoe credentials stay in gitignored .env. Expired pricing blocks inference until official prices are verified and refreshed.

The generated standalone prototype is independently usable:

    python3 artifacts/core-local-solutions/app.py --port 8091

Open http://127.0.0.1:8091. Run its actual tests:

    python3 -I artifacts/core-local-solutions/verify.py
